# 🛒 E-Commerce API Documentation & Interactive API Tester

## 📌 Project Overview

Create a modern, professional **E-Commerce API Documentation and Interactive API Testing Platform**.

The platform should be inspired by modern API documentation websites where developers can:

* Browse API modules
* Select API endpoints
* Read endpoint documentation
* View parameters and request bodies
* Authenticate using Bearer tokens
* Send real API requests
* View JSON responses
* Check status codes and response times
* Copy API code examples

The API modules are:

1. 📦 Products
2. 🗂 Categories
3. 🛒 Orders
4. 👤 Customers
5. 🔐 Authentication
6. 🛍 Shopping Cart
7. 🔎 Product Search
8. 📊 Inventory / Stock
